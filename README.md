# Daily Bloom

An aesthetic, mobile-friendly daily wellness tracker for meals, calories, steps, water, and simple habits.

## Features

- Track meals and calories against a 1,500 kcal daily goal.
- Log steps toward a 10,000-step goal.
- Track water intake toward a 5,000 ml goal with quick-add buttons.
- Check off workout, exercise, six hours of study, and prayer habits.
- Save progress in your browser; each new day starts with a fresh tracker.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.
